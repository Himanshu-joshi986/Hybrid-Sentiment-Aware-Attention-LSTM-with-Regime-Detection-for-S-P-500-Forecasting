SARLD — Sentiment-Aware Regime-conditioned
LSTM with Attention & Decomposition

This paper presents SARLD, a novel hybrid deep learning architecture for S&P 500 closing-price prediction that simultaneously integrates four orthogonal innovations: Bahdanau-style temporal attention over BiLSTM hidden states, Hidden Markov Model-based market regime conditioning (bull/bear/sideways), Empirical Mode Decomposition trend extraction, and a sentiment fusion score combining VADER + TextBlob weighted by headline count. The full model achieves R² = 0.9142, MAE = $65.75, and MAPE = 1.48% on unseen data, outperforming all ablated variants and the unidirectional LSTM baseline by a substantial margin.

02 Model architecture & novel contributions

SARLD extends the BiLSTM backbone with three simultaneous research contributions, each independently validated by the ablation study. The temporal attention layer provides interpretability by exposing which historical days influenced each prediction — a critical requirement for regulatory and academic acceptance.

C1 Attention
Temporal Attention over LSTM hidden states
Bahdanau-style additive attention computes a context vector as the weighted sum of all 60 LSTM hidden states. Learned weights expose which historical days influenced each prediction — making the model interpretable and auditable.
Bahdanau et al., 2015 · Sang & Li, 2024
C2 HMM Regime
Market Regime Detection via 3-state Gaussian HMM
Log-returns + 10-day rolling volatility are fed to a 3-state Gaussian HMM (bull / bear / sideways). Each trading day receives a regime label as a categorical input feature — a gap in most LSTM forecasting literature.
Hamilton, 1989 · Ang & Timmermann, 2012
C3 Sentiment
Sentiment Fusion Score + EMD Trend Component
VADER + TextBlob sentiment scores are fused and weighted by daily headline count (news volume as importance proxy). EMD Hilbert–Huang envelope provides a noise-reduced trend signal as an additional feature.
Hurst, 1998 · Bollen et al., 2011
C4 Novel Metric
Directional Accuracy (DA) — novel evaluation metric
Percentage of trading days where the predicted price direction (up/down) matches the actual. More relevant for trading applications than R² alone. SARLD achieves 54.20% DA — above random-walk baseline of 50%.
Lopez de Prado, 2018

06 Temporal attention weight analysis — interpretability

By visualizing where the attention layer focuses within the 60-day lookback window, we can explain which historical days influenced each prediction. This provides model interpretability — a major advantage for academic and regulatory acceptance. The model consistently places higher weight on the 5–15 most recent days, with a secondary focus on week 5 (days 28–35).

07 Walk-forward validation — eliminating look-ahead bias

Standard train/test split can still overfit to the test period. Walk-forward (expanding-window) validation trains on all data up to each fold boundary and tests on the next unseen chunk, mimicking real-world deployment — the gold standard for financial ML evaluation (Lopez de Prado, 2018).
